## خروجی
- مسیر مرورگر `/review/interactive` زیر `/review/layout.tsx` (متادیتای `noindex,nofollow`) و CSS واکنش‌گرا و راست‌به‌چپ.
- چهار دکمه وضعیت: **منبع تأیید نشده (پیش‌فرض)**، **منبع در دسترس نیست**، **نمونه کاملاً ساختگی**، **نشست یا اختیار منقضی**. تغییرها فقط `useState` محلی هستند.
- چهار کارت وضعیت عضویت، دارایی سهام، درخواست خریدوفروش و اطلاعیه‌ها؛ حالت پیش‌فرض و نامعتبر همواره `—`، نه صفر. حالت «نمونه کاملاً ساختگی» چند مقدار **ثابت و مشخصاً بی‌اعتبار** را فقط برای بررسی فرم کارت نشان می‌دهد. هیچ tenant، Party، موبایل، حساب، شماره پرونده، درخواست رسمی یا منبع سهام واقعی وجود ندارد.
- ۱۱ پیوند به صفحات بازبینی جاری از همان `NAV_IDS` و `shareholderNavigation` مرجع واحد، بدون افزودن منوی جدید به پنل احراز هویت‌شده.
- `aria-pressed`، `aria-live`، کلیدهای Tab/Enter و :focus-visible، ستون‌بندی موبایل و حالت reduce-motion.
- افزودن دو فایل TSX جدید به پارسر AST و یک درخواست HTTP واقعی `GET /review/interactive` در `smoke-next-otp.mjs` با کنترل برچسب‌ها؛ تست `scripts/ci/test_shareholder_w1_synthetic_dashboard.py` شامل هشت کنترل آفلاین.
- **هیچ فایل API، Nest، SQL migration، Role، RLS، کوکی، OTP، مسیر `/modules/*`، عملیات مالی یا واقعی تغییر نکرده است.**

## قواعد امنیت و UX
- این مسیر فقط preview است؛ اگر Deployment Protection/SSO برقرار نشده باشد، اشتراک عمومی آن به عنوان فضای حفاظت‌شده مجاز نیست. metadata `robots:noindex` کنترل دسترسی نیست.
- در source component هیچ `fetch`، `localStorage`، `sessionStorage`، `document.cookie`، `navigator.sendBeacon`، `WebSocket` یا `POST` وجود ندارد.
- نمایش «۱۲۵ سهم» یک مقدار ساختگی مشخص و صرفاً آزمایش چیدمان است. این مقدار هیچ منبع، تأیید حقوقی، نام تعاونی یا نسخه دفتر سهام ندارد؛ محصول اصلی هنگام عدم مجوز همان `—` را نشان می‌دهد.
- Child06 عضویت ۹ کنترل و Child07 دفتر سهام ۱۰ کنترل Pending، Child07 تاریخچه معامله ۷ کنترل و Child09 اطلاعیه ۸ کنترل Pending می‌مانند.
- گردش‌کار رسمی خریدوفروش، قفل سهم و انتقال، پرداخت مستقیم خریدار به فروشنده، انتشار اطلاعیه رسمی و شفافیت اطلاعات قانونی در این PR تغییری نکرده‌اند. **کیف پول و حسابداری عمومی در MVP پلتفرم طراحی نمی‌شود.**
