# ADR-000 — pending technical platform decision

**Status:** AWAITING_APPROVAL. Approved source docs are deliberately technology-neutral.

Must compare at least: (1) React/Next.js app stack and backend runtime; (2) alternative framework options; (3) PostgreSQL / tenant isolation and RLS strategy; (4) Queue, storage, auditing and event processing; (5) Vercel protected Preview + ArvanCloud Production independent configuration; (6) data residency, cost, security and future migrations.

The present preview is dependency-free HTML/CSS/JS imported from a historic prototype, **not** a production framework decision. No production technology or database service has been provisioned.
